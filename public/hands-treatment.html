Which manicure should I choose?

Choose classic for regular polish, gel for a longer-lasting colour, or IBX when natural nails need extra care.

Can existing gel be removed?

Yes. Select the option that includes either a new gel application or a classic manicure afterwards.

Will the result look natural?

Yes. Shape, length and colour are discussed before treatment so the result feels right for you.
