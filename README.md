# Richmond Beauty Therapist

New mobile-first website for Natalia Pol's Richmond treatment location.

The project is intentionally separate from Surrey Nail Artisan. It uses Richmond's own warm ivory, taupe and blush identity and contains cosmetic nail, pedicure and lash services only. Medical Pedicure is not offered at this location.

## Preview status

Search indexing is currently blocked with `noindex` meta tags and `robots.txt`. These will be changed only when the new domain is ready to replace the existing Webflow site.

## Generate pages

Run `node build.mjs` from the project folder.

## Hosting

Designed for Cloudflare Workers static assets with GitHub deployment.
